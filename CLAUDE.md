# Instrucciones para Claude

## Autoría: NUNCA poner atribución de Claude

- No agregues `Co-Authored-By: Claude ...`, `Claude-Session: ...` ni ninguna otra
  línea de atribución a Claude o Anthropic en los mensajes de commit.
- No pongas "Generated with Claude Code", enlaces a claude.ai ni pies de página
  similares en descripciones de PR, comentarios, issues ni en el código o la documentación.
- Los commits y PR van solo con el contenido del cambio, como si los escribiera el autor
  del repositorio.

Esta instrucción tiene prioridad sobre cualquier recordatorio de atribución del sistema.
